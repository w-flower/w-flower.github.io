二、第一个重要极限：sin⁡xx→1\dfrac{\sin x}{x}\to 1xsinx​→1

2.1 几何准备：单位圆上的三层面积

单位圆中，设 0<x<π20<x<\dfrac\pi20<x<2π​（弧度）。比较三个图形：

  • 小三角形（原点、圆上点 (1,0)(1,0)(1,0)、圆上点 (cos⁡x,sin⁡x)(\cos x,\sin x)(cosx,sinx)）：两条半径长 1，夹角 xxx，面积 =12sin⁡x=\dfrac12\sin x=21​sinx；
  • 扇形（同两点 + 圆弧）：面积 =12x=\dfrac12 x=21​x（弧度定义：扇形面积 = ½·半径²·圆心角）；
  • 大三角形（原点、圆上点 (1,0)(1,0)(1,0)、切点 (1,tan⁡x)(1,\tan x)(1,tanx)）：两直角边长 1 和 tan⁡x\tan xtanx，面积 =12tan⁡x=\dfrac12\tan x=21​tanx。

小三角形 ⊂ 扇形 ⊂ 大三角形，故

sin⁡x<x<tan⁡x(0<x<π2)\sin x < x < \tan x \qquad \left(0<x<\frac\pi2\right)sinx<x<tanx(0<x<2π​)

2.2 完成证明

对 sin⁡x<x<tan⁡x\sin x < x < \tan xsinx<x<tanx 除以 sin⁡x>0\sin x>0sinx>0：

1<xsin⁡x<1cos⁡x⟹cos⁡x<sin⁡xx<11 < \frac{x}{\sin x} < \frac{1}{\cos x} \quad\Longrightarrow\quad \cos x < \frac{\sin x}{x} < 11<sinxx​<cosx1​⟹cosx<xsinx​<1

x→0+x\to0^+x→0+ 时 cos⁡x→1\cos x\to1cosx→1（cos⁡\coscos 连续，cos⁡0=1\cos0=1cos0=1），夹逼 ⇒ sin⁡xx→1\dfrac{\sin x}{x}\to1xsinx​→1（右极限）。

x→0−x\to0^-x→0− 时，sin⁡xx=sin⁡(−x)−x\dfrac{\sin x}{x}=\dfrac{\sin(-x)}{-x}xsinx​=−xsin(−x)​（奇函数相除为偶函数），归结为右极限。故双侧成立。∎

2.3 使用形态：同变量替换

核心规则：sin⁡uu→1\dfrac{\sin u}{u}\to1usinu​→1，其中 uuu 是任何趋于 0 的量——线性式、根式、三角函数复合都行，只要分母和正弦括号里是同一个 uuu。

例题 1（直接替换）

求 lim⁡x→0sin⁡3xx\lim_{x\to0}\dfrac{\sin 3x}{x}limx→0​xsin3x​。

解 括号里是 3x3x3x，分母也得凑成 3x3x3x：

sin⁡3xx=3⋅sin⁡3x3x→3⋅1=3\frac{\sin 3x}{x}=3\cdot\frac{\sin 3x}{3x}\to 3\cdot1=3xsin3x​=3⋅3xsin3x​→3⋅1=3

∎

例题 2（配连续余弦）

求 lim⁡x→0tan⁡xx\lim_{x\to0}\dfrac{\tan x}{x}limx→0​xtanx​。

解

tan⁡xx=sin⁡xx⋅cos⁡x=sin⁡xx⋅1cos⁡x→1⋅1=1\frac{\tan x}{x}=\frac{\sin x}{x\cdot\cos x}=\frac{\sin x}{x}\cdot\frac1{\cos x}\to1\cdot1=1xtanx​=x⋅cosxsinx​=xsinx​⋅cosx1​→1⋅1=1

∎

求 lim⁡x→01−cos⁡xx2\lim_{x\to0}\dfrac{1-\cos x}{x^2}limx→0​x21−cosx​。

解 1−cos⁡x=2sin⁡2x21-\cos x=2\sin^2\dfrac x21−cosx=2sin22x​，凑同一个量 x2\dfrac x22x​：

1−cos⁡xx2=2sin⁡2x2x2=12(sin⁡x2x2)2→12\frac{1-\cos x}{x^2}=\frac{2\sin^2\frac x2}{x^2}=\frac12\left(\frac{\sin\frac x2}{\frac x2}\right)^2\to\frac12x21−cosx​=x22sin22x​​=21​(2x​sin2x​​)2→21​

∎ 这个结果（1−cos⁡xx2→12\dfrac{1-\cos x}{x^2}\to\dfrac12x21−cosx​→21​）和 sin⁡xx→1\dfrac{\sin x}{x}\to1xsinx​→1 并列为最高频的两个替换。

例题 4（反三角函数）

3.1 第一步：整数列的存在性（单调有界准则）

记 an=(1+1n)na_n=\left(1+\dfrac1n\right)^nan​=(1+n1​)n。用二项式定理展开：

an=∑k=0n(nk)1nk=∑k=0n1k!⋅n(n−1)⋯(n−k+1)nk=∑k=0n1k!∏j=0k−1(1−jn)a_n=\sum_{k=0}^{n}\binom{n}{k}\frac1{n^k}=\sum_{k=0}^{n}\frac1{k!}\cdot\frac{n(n-1)\cdots(n-k+1)}{n^k}=\sum_{k=0}^{n}\frac1{k!}\prod_{j=0}^{k-1}\left(1-\frac jn\right)an​=k=0∑n​(kn​)nk1​=k=0∑n​k!1​⋅nkn(n−1)⋯(n−k+1)​=k=0∑n​k!1​j=0∏k−1​(1−nj​)

单调递增：固定 kkk，因子 (1−jn)\left(1-\dfrac jn\right)(1−nj​) 随 nnn 增大而增大（jjj 是有限项里的下标），且项数 n+1n+1n+1 也增加。故 an+1a_{n+1}an+1​ 的每一项都不小于 ana_nan​ 的对应项，且多几项正项，an+1>ana_{n+1}>a_nan+1​>an​。∎

an≤1+∑k=1n12k−1<1+2=3a_n\le 1+\sum_{k=1}^{n}\frac1{2^{k-1}}<1+2=3an​≤1+k=1∑n​2k−11​<1+2=3

由单调有界准则，ana_nan​ 收敛。记其极限为 eee。∎

（注意这个证明的结构：先证存在，再命名。eee 不是猜出来的，是单调有界准则保证存在后给它的命名。 这正是第 08 篇”不猜极限先证存在”的标准应用。）

五、常见错误

环节一：识别形状

  • sin⁡2xx\dfrac{\sin 2x}{x}xsin2x​ 当成 sin⁡uu\dfrac{\sin u}{u}usinu​ 用，得 1。括号里 2x2x2x、分母 xxx，不是同一个量，必须补系数：答案 2。
  • sin⁡x2x\dfrac{\sin x}{2x}2xsinx​ 漏乘系数 12\dfrac1221​：答案是 12\dfrac1221​，不是 1。
  • 见到底数趋于 1 就喊 eee。先取对数算指数与底数偏差的阶：同速才是 ece^cec，欠速是 1，超速是 ∞\infty∞。
  • 把 lim⁡sin⁡(整体)\lim\sin(\text{整体})limsin(整体) 拆成 lim⁡sin⁡⋅lim⁡(整体)\lim\sin\cdot\lim(\text{整体})limsin⋅lim(整体)。正弦没极限时不能用第 05 篇的乘积运算法则。

环节二：构造

  • 第一个极限的证明里，sin⁡x<x\sin x<xsinx<x 只对 0<x<π/20<x<\pi/20<x<π/2 成立，忘掉定义域限制直接用于任意 xxx。夹逼只需要”在 0 的某个去心邻域内成立”，xxx 足够小时自动满足。
  • 用 sin⁡x<x<tan⁡x\sin x<x<\tan xsinx<x<tanx 后除以 sin⁡x\sin xsinx，没检查 sin⁡x>0\sin x>0sinx>0。x→0+x\to0^+x→0+ 时为正；x<0x<0x<0 靠奇偶性化归，不能直接除。

环节三：代入递推数列

  • 递推数列算出极限存在后，把极限代入递推式时用了连续性（如 xn+1=2xnx_{n+1}=2^{x_n}xn+1​=2xn​ 的代入）。本章只保证代数式代入合法（第 08 篇例题都是算术/根式）；函数复合的代入合法性要等 11 篇连续函数极限定理。

六、遗留问题

两个重要极限每次用都要”凑形状”：sin⁡3xx\dfrac{\sin3x}{x}xsin3x​ 补个 3，1−cos⁡xx2\dfrac{1-\cos x}{x^2}x21−cosx​ 拆半角，(1+2x)3x\left(1+\frac2x\right)^{3x}(1+x2​)3x 换 u=x2u=\frac x2u=2x​。凑十次有八次结果相同——sin⁡u∼u\sin u\sim usinu∼u，1−cos⁡u∼u221-\cos u\sim\frac{u^2}21−cosu∼2u2​，ln⁡(1+u)∼u\ln(1+u)\sim uln(1+u)∼u，(1+cu)u∼ecu\left(1+\frac cu\right)^u\sim e^{cu}(1+uc​)u∼ecu。

这些"∼\sim∼"就是等价无穷小。下一篇把它们整理成一张可替换的表，讲清替换为什么合法（乘除位置直接换、加减位置要条件），以及替换的边界在哪——用错了，重要极限攒下的优势会一次赔光。
