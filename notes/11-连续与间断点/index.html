第 11 / 15 讲

前面算极限时，我们一直默认函数在所论点附近”表现良好”：能代入、能拆乘、能取对数。cos⁡x\cos xcosx 在 0 点可以随便代入，取整函数 [x][x][x] 在整数点不行。这个”表现良好”的精确名字，就叫连续。本篇先给定义和几种等价说法，再用一棵判断树把间断点完全分类，最后说明连续函数的运算封闭性——正是它把前面所有例题里”代入法”的隐含假设变成了合法操作。

一、定义与等价形式

连续的定义其实只有一句话：

fff 在 x0x_0x0​ 连续   ⟺  \iff⟺ lim⁡x→x0f(x)=f(x0)\lim_{x\to x_0}f(x)=f(x_0)limx→x0​​f(x)=f(x0​)。

一个等式可以拆成三个必要条件，缺一不可，缺了就是间断：

  1. f(x0)f(x_0)f(x0​) 有定义；
  2. lim⁡x→x0f(x)\lim_{x\to x_0}f(x)limx→x0​​f(x) 存在；
  3. 两者相等。

前面讲极限时只关心第 2 条；连续把第 1、3 条也纳进来。函数值就是给极限钉上的”封口钉”——钉上了，函数在所论点就表现良好。

定义（极限语言） fff 在 x0x_0x0​ 连续   ⟺  \iff⟺ ∀ε>0, ∃ δ>0\forall\varepsilon>0,\ \exists\,\delta>0∀ε>0, ∃δ>0，当 ∥x−x0∥<δ\|x-x_0\|<\delta∥x−x0​∥<δ 时 ∥f(x)−f(x0)∥<ε\|f(x)-f(x_0)\|<\varepsilon∥f(x)−f(x0​)∥<ε。

注意和极限定义的唯一差别：这里 ∥x−x0∥<δ\|x-x_0\|<\delta∥x−x0​∥<δ 包含 x=x0x=x_0x=x0​ 本身（极限定义是去心邻域 0<∥x−x0∥<δ0<\|x-x_0\|<\delta0<∥x−x0​∥<δ）。连续要求在 x0x_0x0​ 点也过关——而它在 x0x_0x0​ 点自动过关（∥f(x0)−f(x0)∥=0\|f(x_0)-f(x_0)\|=0∥f(x0​)−f(x0​)∥=0），所以差别不在不等式，在这个点是否被纳入考察范围。

定义（增量语言） 记 Δx=x−x0\Delta x=x-x_0Δx=x−x0​、Δy=f(x0+Δx)−f(x0)\Delta y=f(x_0+\Delta x)-f(x_0)Δy=f(x0​+Δx)−f(x0​)。fff 在 x0x_0x0​ 连续   ⟺  \iff⟺ Δx→0\Delta x\to0Δx→0 时 Δy→0\Delta y\to0Δy→0。

增量语言是下一章（导数）的母语——导数就是 Δy/Δx\Delta y/\Delta xΔy/Δx 的极限，而连续性保证分母趋于 0 时分子也趋于 0，即导数计算里不会出现”分子不趋于 0”的病态。附录 B 的”可导必连续”就用增量语言三行证完。

单侧连续：

  • 左连续：lim⁡x→x0−f(x)=f(x0)\lim_{x\to x_0^-}f(x)=f(x_0)limx→x0−​​f(x)=f(x0​)；
  • 右连续：lim⁡x→x0+f(x)=f(x0)\lim_{x\to x_0^+}f(x)=f(x_0)limx→x0+​​f(x)=f(x0​)；
  • fff 在 x0x_0x0​ 连续   ⟺  \iff⟺ 左右都连续。

区间上连续：fff 在 (a,b)(a,b)(a,b) 内每点连续；在 [a,b][a,b][a,b] 连续 = 内部每点连续 + aaa 点右连续 + bbb 点左连续（端点只要求单侧）。

二、间断点：一棵判断树

x0x_0x0​ 是间断点，即三条必要条件至少破了一条。分类只需按一个顺序往下问：

x₀ 是间断点
├─ 左、右极限都存在吗？
│  ├─ 都存在
│  │  ├─ 相等？
│  │  │  ├─ 相等但 ≠ f(x₀)（或 f(x₀) 无定义）→ 第一类·可去间断
│  │  │  └─ 相等且 = f(x₀)                          → 其实连续，不是间断
│  │  └─ 不相等                                      → 第一类·跳跃间断
│  └─ 至少一个不存在
│     ├─ 至少一侧为 ∞                                → 第二类·无穷间断
│     └─ 有界但振荡（两侧都不存在且不发散到 ∞）       → 第二类·振荡间断

命名逻辑（不是硬背，是树的分支）：

  • 第一类 = 左右极限都存在（“两边都站得稳”）；其中能靠”改一个点的值”修复的叫可去，落差固定的叫跳跃。
  • 第二类 = 至少一侧极限不存在；不存在的方式是冲向无穷的叫无穷间断，是有界振荡的叫振荡间断。

证明 fff 在 x0x_0x0​ 连续 ⇒ lim⁡f=f(x0)\lim f=f(x_0)limf=f(x0​)。∎

五、常见错误

环节一：验证连续

  • 忘了”有定义”这条。sin⁡xx\dfrac{\sin x}xxsinx​ 在 0 点极限存在但不连续——无定义。连续是三条件的合取，极限只是其中一条。
  • 在定义域端点用双侧连续。[a,b][a,b][a,b] 端点只要求单侧，说”fff 在 aaa 不连续因为左极限不存在”是错的——端点没有左邻域，不考察左极限。

环节二：分类间断点

  • 跳过单侧极限直接看 f(x0)f(x_0)f(x0​)。分类树的第一问永远是”左右极限在不在”，f(x0)f(x_0)f(x0​) 只在最后区分”可去 vs 连续”时登场。
  • 把”极限不存在”一律叫振荡间断。不存在的方式有两种：冲向无穷（无穷间断）和有界振荡（振荡间断），先看有没有 ∞\infty∞。
  • 左右极限都存在但不相等时，因为”补个值”的直觉叫它可去。补点只能补”极限存在”的洞，左右不等的洞补不了，是跳跃。

环节三：用运算封闭性

  • 对间断点套四则运算。定理要求 f,gf,gf,g 在同一点连续；1/x1/x1/x 在 0 不连续，11/x=x\dfrac{1}{1/x}=x1/x1​=x 在 0 连续，但这不是运算封闭性的功劳（商的分母在 0 为 0，条件不满足）。
  • 代入时没查定义域。ln⁡x\ln xlnx 在 x≤0x\le0x≤0、x\sqrt{x}x​ 在 x<0x<0x<0、tan⁡x\tan xtanx 在 π2+kπ\dfrac\pi2+k\pi2π​+kπ 都不在定义域，代入法在这些点一律失效。

六、遗留问题

连续是”点点表现好”，但极限章节最后的三个定理要的是整体表现：闭区间上的连续函数一定能取到最大值？一定能穿过 0？一定能取到中间每个值？

三件事单看都”显然”，证明却需要把 06–08 篇的全部库存（局部有界、致密性、区间套、单调有界）组合使用。特别是零点定理——它是下下一章”一致连续”之外、方程近似求根（二分法）的理论靠山。下一篇：闭区间三大定理。
