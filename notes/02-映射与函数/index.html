这一篇要解决的问题是：我们研究的对象”函数”到底是什么？答案先把函数放回更一般的”映射”框架里看——函数 = 定义域 + 对应法则，两者缺一不可；单射、满射决定逆映射存不存在；复合映射则是后面”换元、链式”一切操作的根。

一、映射：函数的一般形态

定义：映射 f:A→Bf:A\to Bf:A→B 是一个规则，对每个 x∈Ax\in Ax∈A，唯一确定一个 y∈By\in By∈B，记 y=f(x)y=f(x)y=f(x)。

  • AAA：定义域（决定”能代什么”）
  • BBB：到达域
  • fff：对应法则（决定”怎么算”）
  • 像集：f(A)={f(x):x∈A}f(A)=\{f(x):x\in A\}f(A)={f(x):x∈A}

决定一个函数的只有两件事：定义域 + 对应法则。（原笔记把它写在最顶上，是因为考试里”f(x)=x2f(x)=x^2f(x)=x2 与 g(x)=x2, x∈(0,1)g(x)=x^2,\ x\in(0,1)g(x)=x2, x∈(0,1) 是不是同一函数”这类题，答案全看这两条。）

二、三种映射与逆映射

类型定义有没有反函数
满射（到上）∀y∈B, ∃x∈A: f(x)=y\forall y\in B,\ \exists x\in A:\ f(x)=y∀y∈B, ∃x∈A: f(x)=y，即 f(A)=Bf(A)=Bf(A)=B—
单射（一对一）x1≠x2⇒f(x1)≠f(x2)x_1\neq x_2\Rightarrow f(x_1)\neq f(x_2)x1​=x2​⇒f(x1​)=f(x2​)单射才有逆映射
双射既单又满逆映射是双射
  • 恒等映射：I(x)=xI(x)=xI(x)=x，任何映射的”什么都不做”。N→R\mathbb{N}\to\mathbb{R}N→R 的嵌入就是”数列是函数的特例”的口子。
  • 逆映射：只有单射 f:A→Bf:A\to Bf:A→B 才有 f−1:f(A)→Af^{-1}:f(A)\to Af−1:f(A)→A，满足 f−1(f(x))=xf^{-1}(f(x))=xf−1(f(x))=x。
  • 复合映射：g:A→B, f:B→Cg:A\to B,\ f:B\to Cg:A→B, f:B→C，则 f∘g:A→Cf\circ g:A\to Cf∘g:A→C，(f∘g)(x)=f(g(x))(f\circ g)(x)=f(g(x))(f∘g)(x)=f(g(x))。

【判断树】问”有没有反函数”：

  1. 先问是不是单射（水平线检验：任意水平线与图像至多一个交点）；
  2. 单射 ⇒\Rightarrow⇒ 在像集上有逆；再问是否满射，决定逆映射的定义域是全 BBB 还是只是 f(A)f(A)f(A)。

三、函数：数集到数集的映射

一元函数：f:D⊂R→Rf:D\subset\mathbb{R}\to\mathbb{R}f:D⊂R→R，∀x∈D, ∃! y=f(x)\forall x\in D,\ \exists!\,y=f(x)∀x∈D, ∃!y=f(x)。 二元函数：f:D⊂R2→Rf:D\subset\mathbb{R}^2\to\mathbb{R}f:D⊂R2→R，∀(x,y)∈D, ∃! z=f(x,y)\forall(x,y)\in D,\ \exists!\,z=f(x,y)∀(x,y)∈D, ∃!z=f(x,y)。 多元（向量值）函数：f:D⊂Rn→Rmf:D\subset\mathbb{R}^n\to\mathbb{R}^mf:D⊂Rn→Rm，

∀x=(x1,…,xn)∈D, ∃! y=(y1,…,ym)=(f1(x1,…,xn),…,fm(x1,…,xn)).\forall x=(x_1,\dots,x_n)\in D,\ \exists!\,y=(y_1,\dots,y_m)=(f_1(x_1,\dots,x_n),\dots,f_m(x_1,\dots,x_n)).∀x=(x1​,…,xn​)∈D, ∃!y=(y1​,…,ym​)=(f1​(x1​,…,xn​),…,fm​(x1​,…,xn​)).

记号（原笔记原样）：

  • fff：对应法则本身；
  • f(x)f(x)f(x)：函数在 xxx 处的值（一个数，不是函数）；
  • y=f(x), x∈Dy=f(x),\ x\in Dy=f(x), x∈D：定义在 DDD 上的函数。

【易错】fff 与 f(x)f(x)f(x) 不是一回事。lim⁡f(x)\lim f(x)limf(x) 里写 fff 是偷懒的简写，意思是”函数值的极限”。说”f(x)f(x)f(x) 连续”是口语，严格说”fff 在点连续”。

四、初等函数（下一节立刻要用）

由基本初等函数（幂、指数、对数、三角、反三角）经有限次四则运算与复合得到的函数，叫初等函数。记住第 11 篇的结论：初等函数在定义区间内每点连续——这是第 03 篇起大部分”代入求值”式极限的合法性来源。
