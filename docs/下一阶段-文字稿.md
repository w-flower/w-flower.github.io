## 一、标签页 `/tags/`（已落地）

页面自己带的三句话：

```
标题：标签 / Tags
副标题：共 22 个标签，来自 15 篇内容。字越大，挂的东西越多。
页脚说明：点一个标签，会跳到对应列表页并自动筛到它。
          笔记的标签是知识点（夹逼、连续…），课程名单独放在每篇的信息栏里。
```

**写法说明**
- 副标题用数字（22 / 15）。不写「探索知识的海洋」这类。
- 页脚那句是在解释规则，不是营销——标签和课程名分开这件事不说清楚，读者会以为漏了「工科数学分析」。
- 副标题的「共 N 个标签」是构建期算出来的，不用手改。

**导航那一项**（`src/copy.ts` 的 `nav` 里「其他」的 children）：

```ts
{ label: "全部内容", href: "/archive/" },
{ label: "标签", href: "/tags/" },
{ label: "起始页", href: "/start/" },
{ label: "RSS 订阅", href: "/rss.xml" },
```

## 二、摘要字段 `summary`（已落地）

frontmatter 约定，跟 `posts` 用同一个字段名：

```yaml
---
title: '07 夹逼三板斧：构造夹逼组的决策树'
date: 2026-10-14
course: '工科数学分析'
status: growing
summary: '夹逼难在造不等式：n 项和用放缩、取整用定义不等式、和式像 Riemann 和就转积分。'
tags: ['极限', '夹逼', '放缩']
draft: false
---
```

**写摘要的两条**（照这个写的 15 篇）
1. 说这篇解决什么问题，不写「本文介绍了…」；
2. 30–45 字。列表卡片不截断的位置差不多就这么多，自己先断好比被切掉好。

**兜底**：不填 `summary`，列表卡片自动截正文开头 110 字。现在 15 篇都填了。

## 三、标签的取词规则（新约定，写下来以后好守）

标签回答的是「**这篇讲了什么**」，课程名回答「**哪门课**」。两者分开。

- 每篇 2–3 个，从**同一门课内部的知识点**里取，不重复课程名；
- 优先选**会在多篇之间复用**的词（极限、连续、夹逼、数列），别每篇都造新词——
  造出来全是 1 篇的标签，标签页就退化成目录了；
- 不写「数学」「笔记」这种等于没写的词。

现在的分布：极限 6、连续 4，其余 1–2。够用；以后写新篇先想「能不能挂到已有标签上」。

## 四、blog-admin 界面文案（已落地）

| 位置 | 文案 |

## 六、写文案时的三条（沿用）

1. **不写「欢迎」「希望对你有帮助」「让我们一起」**。404 页的「这条路通向一堵墙」比任何欢迎语都好。
2. **能用数字就用数字**：「共 22 个标签」比「浏览全部标签」有用。
3. **承认局限比假装完整好**。
