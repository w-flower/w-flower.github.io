## 三、P1 写作：别新建 `/write`，增强 blog-admin

### 3.1 一个容易被忽略的事实

`D:\Projects\blog-admin` 那个 Python 工具**已经能写盘**，而且绑的是 `0.0.0.0`——手机上开 `http://10.195.172.125:8787` 就能用。它现在能做：新建四类内容、改站点信息、改界面文案、上传图片、一键构建。

### 暗色：新增组件必须同批改 dark 覆盖

上一轮修掉 5 处漏网（文章页标签胶囊、标签首胶囊、GitHub/B站 按钮、分页悬停、分页当前页），这一轮又补了第 6 处：左栏标签按钮 `.chip`（它 `hover` 时是纯白底，暗色下浅灰字直接消失）。根因都一样：

**规矩**：组件里出现 `background: rgba(255,255,255,0.4~0.9)` 或 `#fff`，同一批改动里必须带上：

```css
[data-theme="dark"] .新组件 {
  background: var(--surface-2);
  border-color: rgba(255, 255, 255, 0.1);
}
```

自查用 `scripts/dark-audit.py`（扫硬编码浅色底有没有对应 dark 规则）。
**P1 的第二屏因为复用 `.note-card`，天然不用新增规则——这是故意的：能复用就复用。**
