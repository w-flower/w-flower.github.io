# 主页改版设计稿 v1

> 依据：你手绘的 5 页说明 + 2026 年前端动效基线（CSS Scroll-driven Animations 已成为 Baseline 2026，Chrome / Edge / Safari 26 原生支持，无需 polyfill）。
> 一句话方向：**从「深色暖墨 + 朱红」整体改成「浅色 + 毛玻璃 + 分层动态背景」**。这是一次整站换皮，不是局部调色。

## 0. 先摆一个必须你拍板的冲突

现在的站是深色暖墨底（`#16110e`）+ 朱红强调（`#ff5a1f`），这是照 wuhobin 那个模板抄的。
你的新说明写的是：**浅色系、圆角、浅色边框、毛玻璃**。两者不兼容。

我的判断：**按你的图走，整站换浅色玻璃风。** 理由——你要记录的是学习笔记和代码，浅色长时间阅读更耐看；毛玻璃在浅色上才出效果，深色上会脏。深色主题不删，留成二期的一个开关。

### 形状与质感
- 卡片圆角 `24px`，内嵌块 `16px`，按钮/胶囊 `999px`

### 字体
- 正文：系统中文栈（`PingFang SC / Microsoft YaHei`），16px / 行高 1.75

### 栅格
- 最大宽 `1200px` 居中
- 左栏固定 `300px` + 右侧流式
- 栏间距 `28px`，页面上下留白 `40px`
- 断点：`1200 / 900 / 640`。≤900px 左栏**折叠成顶部横条**

## 3. 背景分层（三层，从下往上）

这是这次改版的**视觉主角**，比卡片本身重要。

**L0 渐变底**
`linear-gradient(180deg, #eef3fa 0%, #e3eefa 45%, #d7e8f8 100%)`，全屏固定。

**L1 顶部图片层（上半屏）**
- 一张图铺在页面顶部，高度约 `62vh`
- 底部用 `mask-image: linear-gradient(to bottom, #000 45%, transparent 100%)` 溶进底色，**不能有硬边**
- 图片上叠一层极淡白色雾 `rgba(255,255,255,.18)`，把对比压下去，保证文字可读
- 叠一层噪点纹理 `opacity: 0.035`（SVG feTurbulence 生成，静态，不耗性能），消除塑料感
- **视差**：图片随滚动以 0.15 倍速上移（CSS Scroll-driven，见 §4-1）

**L2 底部水波层（下半屏）**
- 三条 SVG 波浪路径，横向无限滚动，速度分别 18s / 26s / 34s，透明度 `.10 / .07 / .05`，颜色都是雾蓝系
- 反向错位：一条向左，两条向右，避免看出循环
- 固定在视口底部（`position: fixed; bottom: 0`），内容滚过去时水波一直在动
- 移动端降到两条 + 降帧（见 §7）

> 为什么不用 canvas 粒子水波：GPU 合成层能跑满 60fps 的方案里，SVG transform 平移动画是最便宜的；canvas 每帧重绘在低端安卓会上 30fps 以下，且耗电。水波要"有呼吸"，不要"有粒子"。

## 4. 动效清单

全部遵守两条硬规则：**只动 `transform` / `opacity` / `filter`**；**时长 ≤ 400ms（循环动画除外）**。

| # | 动效 | 触发 | 实现方式 | 成本 |
|---|---|---|---|---|
| 1 | 顶部图视差 | 滚动 | `animation-timeline: scroll(root)` + `animation-range: 0 100vh` | 合成器，0 JS |
| 2 | 水波循环 | 无限 | `@keyframes` translateX + 3 层错速 | 合成器 |
| 3 | 卡片入场 stagger | 进视口 | `view-timeline` + `animation-range: entry 10% cover 30%`，`animation-delay` 按 index × 60ms | 合成器，0 JS |
| 4 | 卡片光标高光 | 鼠标移动 | `pointermove` → 写 `--mx/--my` CSS 变量 → 径向高光跟随 | 极低 |
| 5 | 卡片 hover 抬升 | hover | `translateY(-4px)` + 边框提亮 | 极低 |
| 6 | 头像描边旋转 | 无限（hover 加速） | `conic-gradient` + `@property --angle` 角度动画 | 低 |
| 7 | 侧栏悬停二层展开 | hover | `grid-template-rows: 0fr → 1fr`（内容自适应高度，不写死 px） | 低 |
| 8 | 侧栏滚动联动位移 | 滚动 | `animation-timeline: scroll(root)` 驱动 `translateY(0 → -24px)` | 合成器，0 JS |
| 9 | 导航胶囊滑块 | 切换分类 | FLIP：取新旧 `getBoundingClientRect` 差值，`transform` 过渡 | 低 |
| 10 | 搜索框聚焦 | focus | 边框提亮 + 外发光环 `box-shadow` + 宽度 `scaleX(1.01)` | 低 |
| 11 | 标题行揭示 | 进视口 | `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` 逐行 | 合成器 |
| 12 | 顶部滚动进度条 | 滚动 | `animation-timeline: scroll(root)` 驱动 `scaleX(0→1)` | 合成器，0 JS |
| 13 | 统计数字 count-up | 进视口 | 小 JS + IntersectionObserver，600ms ease-out | 低 |
| 14 | 页面切换过渡 | 路由跳转 | Astro `<ClientRouter />`（View Transitions API），卡片做 shared element | 低 |
| 15 | **悬停浮层（详情卡）** | 鼠标停留 400ms | 光标旁浮出详情卡，跟随光标带缓动，出边界自动翻转 | 低（单实例复用） |
| 16 | 浮层内行级 stagger | 浮层出现时 | 行元素 `translateY(6px)→0` + opacity，delay 30ms 递增 | 合成器 |

### 明确不做（说明理由，避免你后面问"为什么没有"）
- **Lenis / 平滑滚动劫持**：坏处大于好处。破坏原生滚动条、影响触控板和移动端手感、和无障碍冲突、部分浏览器前进后退异常。2026 年的共识是"别接管滚动"。
- **粒子 / 3D / Three.js**：博客读者是来看字的，不是来看 demo 的。加载成本和移动端功耗不划算。
- **逐字打字机**：中文逐字跳太吵，读起来像卡顿。改用"整行 clip-path 揭示"（#11）。
- **GSAP**：这次能做的都能用原生 CSS 做完，少 25KB+ 依赖。

## 5. 界面逻辑（交互状态机）

### 5.1 左栏个人信息 —— 悬停二层
```
[idle]   头像 + DHua + 一句签名
   ↓ hover 停留 120ms（防误触）
[expanded] 卡片高度展开，露出：
          · 一句话 bio
          · 图标行：GitHub / B站 / 邮箱 / RSS
          · 四格统计：文章 12 · 笔记 30 · 代码 8 · 随笔 41
          · 「所有代码 →」文字链
   ↓ 移出 200ms
[idle]
```
- 用 `grid-template-rows: 0fr / 1fr` 过渡，内容多少都能自适应
- `@media (hover: none)` 触屏设备：**默认展开**，因为它没有 hover 概念，收起等于藏死内容
- 键盘 `Tab` 到卡片时也展开（`:focus-within`）

### 5.2 分类导航 —— 胶囊滑块 + 滚动联动
- 两个入口：**标签库** / **分类**
- 点击 → 右侧内容过滤 → 卡片以 stagger 重新入场（不是硬切）
- 当前项后面一块雾蓝半透明胶囊，用 FLIP 滑过去（#9）
- 滚动时整块左栏轻微上移（#8），制造"跟着页面动"的联动感；但它本身 `sticky`，不会跑出视口

### 5.3 搜索
- 结构：玻璃胶囊 + 放大镜 + 右侧 `/` 提示
- 快捷键 `/` 聚焦，`Esc` 清空并失焦
- `input` 后 **150ms debounce** 再过滤，避免每敲一个字抖动
- 无结果 → 复用已有的 `copy.empty` 空态，文案改成「没找着。换个词试试？」
- 搜索时左栏分类置灰

### 5.4 分页
- 每页 6 张卡
- 底部胶囊按钮组 `‹ 1 2 3 ›`，当前页有实心雾蓝底
- 切页：卡片 stagger 重入 + 内容区顶部 `scrollIntoView({behavior:'smooth'})`
- 页码 > 7 时折叠成 `1 … 4 5 6 … 12`

### 5.5 响应式
| 宽度 | 行为 |
|---|---|
| >1200 | 完整两栏 |
| 900–1200 | 左栏 260px，卡片单列 |
| <900 | 左栏折叠成**顶部横条**：头像 40px + DHua + 标签横向滚动条；搜索框吸顶 |
| <640 | 卡片圆角降到 18px，毛玻璃 blur 降到 10px |

### 5.6 无障碍与降级
- `@media (prefers-reduced-motion: reduce)`：**关掉全部滚动驱动动画和水波**，内容直接可见
- 所有滚动动画包 `@supports (animation-timeline: scroll())`，Firefox 老版本自动降级成静态显示（内容不隐藏）
- `:focus-visible` 统一 2px 雾蓝外环
- 玻璃面板文字对比度按 WCAG AA 校验（`#1b2430` 在 `rgba(255,255,255,.55)` 上 ≈ 13:1，安全）

### 5.7 悬停浮层：鼠标碰上显示详细信息

这是这一轮新加的核心交互。**不是**把卡片原地撑大（那会把整个栅格顶乱），而是**在光标旁边浮出一张独立详情卡**。

**触发与消失**
```
鼠标进入卡片 → 计时 400ms（防误触，划过不弹）
   ↓ 停留满 400ms
浮层淡入（180ms，scale .96→1，translateY 6px→0）
   ↓ 在卡片内移动
浮层跟着光标走，但**有缓动**：每帧 lerp 到目标位置（系数 0.18），不是死贴鼠标
   ↓ 离开卡片
120ms 立即淡出，不等
```

- 400ms 是刻意的：低于 300ms，鼠标扫过列表会一路闪；高于 600ms，感觉"没反应"。
- 缓动跟随是关键。死贴光标的浮层像手套；带一点延迟才像"浮"着。

**位置算法**
```
target = 光标 + (18, 20)
若 target.x + 浮层宽 > 视口右边界 - 16  → 翻到光标左侧：光标.x - 浮层宽 - 18
若 target.y + 浮层高 > 视口下边界 - 16  → 翻到光标上方：光标.y - 浮层高 - 20
```
用 `transform: translate3d()` 定位，不用 `left/top`（避免每帧重排）。

**浮层内容**（比卡片多三层信息）
| 区域 | 内容 |
|---|---|
| 顶行 | 类型色点 + 类型名（文章/笔记/代码/随笔）+ 右侧「400ms → 已读」类的时间戳 |
| 标题 | 完整标题，最多 2 行 |
| 摘要 | 正文前 2 行（40 字截断），比卡片上的摘要多一倍 |
| 元信息行 | 日期 · 字数 · 预计阅读 3 分钟 |
| 标签行 | 全部标签胶囊 |
| 底行 | 「打开 →」提示，颜色雾蓝 |

**技术要点**
- **只用一个浮层 DOM**，全站复用。鼠标移到哪张卡，就把内容替换进去再定位。不是每张卡挂一个浮层——12 张卡挂 12 个浮层 = 12 个 `backdrop-filter` 层，移动端直接崩。
- 浮层是 `position: fixed; z-index: 60; pointer-events: none`。**绝不接收鼠标事件**，否则会和"鼠标离开卡片"打架，导致浮层闪烁。
- 卡片内容通过 `data-*` 属性传给浮层（`data-title` `data-summary` `data-date` `data-tags` `data-kind`），不重复渲染 HTML。
- `will-change: transform` 只在实际显示时加，隐藏时移除，避免常驻合成层。

**降级**
- `@media (hover: none)`：不启用浮层。触屏改为**点一下卡片在本位展开一层**（`grid-template-rows` 同侧栏那套）。
- `prefers-reduced-motion: reduce`：浮层不做缓动跟随，直接定位出现，只留淡入。
- 键盘 `Tab` 到卡片：浮层固定在卡片右侧出现（不跟随光标），`Esc` 关闭。
- 浮层 `aria-hidden="true"`，不参与读屏顺序（它只是视觉增强，信息在卡片里已有）。

**性能红线**
- 整个浮层的动画只有 `transform` + `opacity`。
- 跟随用单个 `requestAnimationFrame` 循环，且**只在浮层可见时跑**；隐藏时循环立即停，不空转。
- 浮层里的 `backdrop-filter` 用 `blur(20px)`，比卡片略高，制造"更靠近用户"的层次。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| `backdrop-filter` 在低端安卓掉帧 | 移动端降到 `blur(10px)`；检测到 `prefers-reduced-motion` 或 `navigator.hardwareConcurrency <= 4` 时退成纯半透明白 |
| 顶部图 + 玻璃卡片，文字可读性可能不足 | 图片上叠白雾 + 卡片内边距够大 + 卡片本身不透明度 0.55 起 |
| 滚动驱动动画 Firefox 支持滞后 | 全部包 `@supports` 闸门，默认内容可见，渐进增强 |
| View Transitions 在某些浏览器后退异常 | Astro `ClientRouter` 自带降级；出现异常直接移除，不影响功能 |
| 水波固定底部可能挡住内容 | z-index 层级锁死：背景 -1 / 内容 1 / 侧栏 2；内容区底部留 120px |

## 10. 落地时改了的三处（与上面稿子不一致，以这里为准）

1. **标题衬线没做。** Windows 上唯一的中文衬线是宋体，在 19px 以上的标题尺寸下就是旧公文感，比无衬线更差。要真衬线只能引入字体文件（思源宋体子集约 2–4MB），首屏会明显变慢，尤其校园网。这一版先用无衬线，靠字重和字距拉层次。`--font-serif` 变量留着了，后面想加直接接。
2. **个人信息悬停展开改成"浮出"而不是"撑开"。** 按稿子做成撑开时，左栏整体高度从 205px 涨到 540px，下面的分类导航被推下去 335px，鼠标一进一出整列都在跳。改成绝对定位浮层（`top: 100%` + 8px 透明过渡区），个人信息卡本身高度不变，展开层像下拉菜单浮在上面。
3. **页面切换过渡（动效 #14）没做。** Astro 的 `<ClientRouter />` 会让所有页内脚本需要重新绑定（`astro:page-load`），当前 `index.astro` 的筛选、分页、浮层都依赖一次性初始化，接进来得整体改写脚本生命周期。收益（一次淡入）不抵风险，先跳过。
